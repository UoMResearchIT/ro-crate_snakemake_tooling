# WRite an R0-Crate with a Snakemake reporter plugin

## Trying out the code.

Easiest way to get this working is to use the pip editable install command:

1) Create a conda env with the latest Snakemake
2) Make sure that env is active, and that `which pip` looks appropriate
3) `pip install -e ./` (from within this directory)

You will be able to edit the source code, and then test the library without having to reinstall.
